My Services

Vulnerability Assessment & Penetration Testing

Identifying security weaknesses using tools like Nmap, OpenVAS, and Metasploit in controlled lab environments such as Metasploitable2. I simulate real-world attack scenarios to assess system exposure.

SIEM Monitoring & Log Analysis

Using Splunk SIEM to collect, forward, and analyze logs from Linux systems and virtual machines. I investigate suspicious activity and build alerts for threat detection and incident response.

Network Traffic Analysis

Capturing and analyzing network packets using Wireshark to detect anomalies, identify protocols, and investigate potential malicious activity in network traffic.

Firewall Configuration & Network Security

Configuring and testing firewall rules using pfSense in virtual environments, focusing on network segmentation, traffic filtering, and secure architecture design.

Security Automation (Python)

Developing simple cybersecurity tools such as port scanners using Python to automate reconnaissance and support basic vulnerability discovery processes.

Security Framework Analysis

Applying the NIST Cybersecurity Framework to evaluate risks, improve security posture, and structure defensive strategies based on industry standards.
